# Release v2.0.1-noc-preflight

This release is the Paperpal/OUP preflight-clean Neuroscience of Consciousness submission snapshot for the Gamma-Code Consensus (GCC) reproducibility package.

Relative to `v2.0.0-noc`, the author-generated analysis code, derived validation outputs, and submission figures are unchanged. The release updates the manuscript package for technical-compliance cleanliness:

- shortened the main manuscript PDF to remain below the NoC/Paperpal 9,000-word preflight threshold;
- reduced the printed bibliography to actively cited references only;
- removed stale version-DOI wording from the manuscript and cover letter;
- retained the Zenodo concept DOI (`10.5281/zenodo.19744969`) as the stable latest-version DOI.

Zenodo identifiers:

- version DOI: `10.5281/zenodo.19818741`;
- concept DOI: `10.5281/zenodo.19744969`.

The release contains:

- the NoC submission manuscript source and PDF;
- supplementary files S1 and S2;
- all author-generated simulation and public EEG/PSG analysis scripts;
- derived result tables, JSON summaries, and figures for Batches 3--18;
- frozen validation specification and reproduction notes.

Raw third-party EEG/PSG datasets are not redistributed. They remain available from their original public repositories and are documented in the manuscript Data Availability statement.
