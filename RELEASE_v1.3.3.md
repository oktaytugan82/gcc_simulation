# Release v1.3.3

Release date: 2026-05-11

This is a manuscript-framing patch over v1.3.2. The computational code, Chennu baseline-holdout outputs, Hermann proxy outputs, and core numerical results are unchanged.

## Changes

- The Hermann et al. 2021 DoC metadata analysis is no longer presented as a main-text result table. The main text now only points to it as a supplementary clinical plausibility check.
- A direct comparison to PCI, dynamic mean-field, and dynamic-connectivity/state-pattern approaches was added to clarify the model's position relative to established consciousness-state frameworks.
- Terminal/paradoxical lucidity framing was reduced. The main claim is now stated as a broader transient re-entry hypothesis for degraded networks, with lucidity-like episodes only as one possible future test case.
- The Mmin degeneration and the ergodicity-type bridge between ensemble Pi and per-subject EEG Pi are stated more explicitly as unresolved limits.
- The final manuscript and supplement PDFs were regenerated after these framing edits.
